# Movie & TV Show Link Finder Bot

A Telegram bot that searches your saved streaming/download sites and returns the direct link to any movie or TV show you ask for.

---

## Features

- `/movie <title>`, `/tv <title>`, `/anime <title>`, and `/game <title>` search configured sites
- Plain text searches for movies
- `/sites`, `/favorites`, `/history`, and `/favorite <title> | <url>` provide lightweight local storage
- Supabase storage keeps history, favorites, and cache off the Raspberry Pi SD card
- Health endpoint at `http://localhost:8080/`

---

## Setup

### 1. Get a Bot Token

1. Open Telegram and search for **@BotFather**
2. Send `/newbot` and follow the steps
3. Copy the token it gives you

### 2. Install dependencies

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` is intentionally empty: the bot uses only the Python standard
library, so it runs on Raspberry Pi OS without compiling lxml or installing large
optional SDKs.

### 3. Configure the token

Copy the example env file and fill in at least the bot token:

```bash
cp .env.example .env
```

Open `.env` and replace the placeholder:

```
BOT_TOKEN=your-telegram-bot-token
```

Set `SUPABASE_URL` and `SUPABASE_KEY` to store history, favorites, and cache
remotely instead of on the Pi SD card. If Supabase is unavailable, the bot
temporarily falls back to local `bot.db`.

Run this SQL once in the Supabase SQL editor:

```sql
create table bot_cache (
  query text primary key,
  response jsonb not null,
  created_at bigint not null
);
create table bot_history (
  id bigint generated by default as identity primary key,
  chat_id bigint not null,
  title text not null,
  category text not null,
  created_at bigint not null
);
create table bot_favorites (
  id bigint generated by default as identity primary key,
  chat_id bigint not null,
  title text not null,
  url text not null,
  created_at bigint not null,
  unique (chat_id, title, url)
);
```

For a private bot, enable Row Level Security and add policies allowing the
service role key to access these tables. Never commit `.env` or expose the
Supabase service key.

### 4. Run the bot

```bash
python bot.py
```

The bot starts polling Telegram. With Supabase configured, normal data is stored
remotely and `bot.db` is only used if the remote service fails.

## Usage

### Search a title

```
/movie Inception
/tv Breaking Bad
/anime Attack on Titan
/game GTA 5
```

The bot also accepts a plain-text title and detects its category automatically.

### View and manage your sites

Use `/sites`, `/favorites`, and `/history` to inspect configured sites and
your saved data. The master can use `/deleteall New_Creation` to delete all
history, favorites, and caches from Supabase and local fallback storage.

The master chat is restricted to the configured Telegram chat ID
`5589716681`. Supabase failures, polling faults, unauthorized delete attempts,
delete failures, and fatal shutdowns are reported to that chat. A completely
powered-off or killed Raspberry Pi cannot send a Telegram message by itself;
use a systemd service with restart enabled if automatic recovery is required.

---

## How the search works

For each configured site, the bot makes a bounded DuckDuckGo HTML search and
only accepts result links whose hostname exactly matches the configured hostname.
At most eight sites are queried with four workers, which keeps memory and CPU
usage reasonable on a Raspberry Pi.

---

## Notes

- Sites must have a publicly accessible search page (no login required)
- The bot searches sites in parallel for speed
- `sites.json` is read from the same folder as `bot.py`
- You can keep the bot running 24/7 on a Raspberry Pi or any Linux server.
- Keep `.env` private and set `BOT_TOKEN` before starting.
- For a low-power Pi, use a 64-bit Raspberry Pi OS image and Python 3.11+.
